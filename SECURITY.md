# Security

Radarchik ships a root helper (Guard: keys behind Touch ID, the SSH-agent relay, the network watch), so security reports matter a lot.

If you find a vulnerability, report it privately: **Security → Report a vulnerability** on this repository. Please don’t open a public issue or pull request for it.

Include what you found, how to reproduce it and which version or commit you tested. You’ll get a reply as soon as possible, and the fix will be credited to you unless you’d rather stay anonymous.
